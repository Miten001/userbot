The in-site browser renders pages through the local GhostShell relay (127.0.0.1 only, with an SSRF guard and proxy support). On this static page it will always sit idle — that is expected. Start it on your machine: 

cd ghostshell
./tools/relay.sh --open        # Node 18+, zero dependencies

# then open:
http://127.0.0.1:8787/browser.html

Search, the embedded viewer and the proxy manager all light up once the relay answers.
