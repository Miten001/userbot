Read this first — the honest version

No browser can make a flagged IP address unflagged. Commercial VPN and datacentre ranges are published in MaxMind, IPQualityScore and IP2Location, and strict sites check every incoming connection against them. That lookup happens on their server, before your browser has rendered a single pixel. Nothing you install can change it.

What does get most people caught is the browser contradicting itself: a German exit IP with an Indian timezone, a proxy tunnel with WebRTC cheerfully publishing the real public IP, or a Windows user-agent sitting on a Retina screen at DPR 2. That second category is entirely fixable, and it's what GhostShell does.

Practical rule: if the site you care about is strict, the IP matters more than the browser. Use a residential or mobile exit. GhostShell then makes sure your browser doesn't give you away on top of it.

Two halves, because half of it is out of reach of extensions

01

The launcher

Runs Chrome in an isolated profile with the flags Chrome exposes no API for:

  • --force-webrtc-ip-handling-policy=disable_non_proxied_udp — stops STUN from gathering your real public IP
  • --disable-quic — QUIC is UDP; most proxies don't tunnel UDP, so Chrome silently connects direct
  • --disable-ipv6 — most VPNs tunnel IPv4 only, and IPv6 walks straight past the tunnel
  • --disable-blink-features=AutomationControlled + --exclude-switches=enable-automation
  • Process-level TZ and --lang, so the whole browser agrees with your exit country
  • Google background chatter off: optimization hints, component update, domain reliability, metrics
02

The extension

A Manifest V3 extension that runs before page scripts and makes the JS surface self-consistent:

  • Strips local/public ICE candidates that aren't your tunnel
  • Rewrites Intl, Date and Accept-Language to the exit timezone and locale
  • Spoofs navigator.geolocation to coordinates that match your exit country
  • Adds deterministic canvas / WebGL / audio noise — stable within a session like a real browser, different across sites
  • Normalises plugins, media device IDs, battery, GPU string, CPU/RAM, permissions
  • Removes navigator.webdriver and every Puppeteer / Playwright / CDP marker

Install

Install the launcher

curl -fsSL https://miten001.github.io/userbot/install.sh | bash

Installs to ~/.ghostshell and links ~/.local/bin/ghostshell.

2

Load the extension once

Run ghostshell, then open chrome://extensions, turn on Developer mode, choose Load unpacked and select ~/.ghostshell/extension. It stays installed in the isolated profile.

3

Tell it where you exit

Open the shield icon and pick your exit country. That sets timezone, locale, Accept-Language and GPS together — setting only one of them is worse than setting none.

Set the timezone yourself

Windows Chrome reads the OS clock for anything that isn't JavaScript. The extension covers Intl and Date, which is what web pages read, but if you want full consistency set your Windows timezone to match your exit country too.

FAQ

Will this make my VPN undetectable?

No, and nothing will. If your exit IP belongs to a known VPN or hosting provider, servers identify it before your browser sends a byte. GhostShell stops your browser from adding evidence on top. For strict sites, the IP is the deciding factor — use a residential or mobile exit.

Is this just an anti-detect browser like Multilogin or Kameleo?

No. Those sell curated fingerprint pools and profile management, generally closed-source and paid. This is ~2,000 lines of plain JavaScript and shell that you can read, aimed specifically at leak closure and self-consistency rather than at impersonating a large number of separate identities.

Why not just use Brave or Firefox with RFP?

They're good on fingerprinting, and Firefox's privacy.resistFingerprinting is a genuinely strong baseline. Neither fixes location inconsistency (your timezone still contradicts your exit IP), and neither blocks the UDP-family leaks when you're on a browser-level proxy rather than a system VPN. Those are the two things that catch people most often.

Do I need both the launcher and the extension?

The extension alone gets you most of the in-page wins. The launcher adds the flags Chrome exposes no API for — QUIC, IPv6, the ICE policy — plus an isolated profile. If you're on a real system VPN, the extension alone is a big improvement; both together is the complete picture.

Why is the canvas noise deterministic instead of random?

Because a real browser returns the same bytes every time you read a canvas. If noise changes on every read, a site that samples twice knows instantly that something is intercepting. GhostShell seeds from the origin plus a per-session salt: identical within a session, different across sites. You look like one distinct real user to each site.

Why does my proxy need to be unauthenticated?

Chrome's chrome.proxy API deliberately omits credentials. Chrome will show its own auth prompt the first time, and that's fine — but for a silent setup, run the tunnel locally (SSH -D, gost, or your VPN client) and point GhostShell at 127.0.0.1.

Does it slow anything down?

Negligibly. The canvas noiser only touches canvases under 96 KB, so image editors and games are unaffected. Audio perturbation runs on every 97th sample and is roughly 140 dB below full scale.

Is this legal?

Hardening your own browser is ordinary privacy practice, and leak protection is what any good VPN setup guide tells you to do. What you then do with it is your business and your responsibility: bypassing geo-restrictions usually breaches the terms of service of the site involved, and using any of this for fraud, evasion of enforcement, or harming others is not what this is for.
