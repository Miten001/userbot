Network / proxy

Chrome cannot store proxy credentials. The chrome.proxy API deliberately omits username/password, so an authenticated proxy will trigger Chrome's own login prompt. For a silent setup, run the proxy locally (SSH tunnel / gost / your VPN client) and point GhostShell at 127.0.0.1. See docs/PROXY-AUTH.md.
A browser proxy is not a VPN. Only TCP is proxied — UDP (QUIC, WebRTC, DNS-over-UDP) can still leak. Use a real system VPN, or launch via ghostshell --proxy which additionally forces --disable-quic and the strict WebRTC policy.

Location consistency

A mismatch here is the loudest signal of all: an IP in Frankfurt with Intl.DateTimeFormat().resolvedOptions().timeZone === "Asia/Kolkata" is a near-certain VPN flag, and no amount of canvas noise will hide it.

Device profile

Applies a coherent set: UA + userAgentData client hints + platform + screen size + CPU/RAM + GPU string. Choosing values piecemeal is how people get caught — e.g. a Windows UA reporting a 2560×1600 Retina screen at DPR 2.

Fingerprint defences

Canvas
Adds deterministic per-site noise. Stable within a session (like a real browser), different across sites.
Audio
Perturbs AudioBuffer / AnalyserNode output ~140 dB below full scale — inaudible, but changes every audio hash.
WebGL
Reports the GPU matching the chosen profile and strips datacentre-specific extensions.
Media devices
Device IDs are stable per-browser and are a top-tier identifier. "Generic" reports one mic + one speaker and no camera.
Font list
Reports a standard Windows font set instead of your real one.
Battery API
Always reports charging at 100% — the real value leaks laptop vs desktop and is rarely needed.
Permissions prompt state
Normalises notification permission to "prompt". Headless Chrome answers "denied", which no real desktop ever does.

Network hardening

WebRTC
Also forces Chrome's disable_non_proxied_udp policy, so STUN cannot gather your real public IP.
Disable QUIC (HTTP/3)
QUIC runs over UDP and commonly bypasses a proxy tunnel. Applied by the launcher; shown here for reference.
Block IPv6
Many VPNs tunnel only IPv4. If you have IPv6, your traffic exits un-tunnelled. Applied by the launcher.
These two are enforced with --disable-quic and --disable-ipv6 at process launch — Chrome exposes no runtime API for them. Run Chrome through ghostshell to apply.
